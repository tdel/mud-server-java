# Feats

Source: [D&D 5e SRD 5.1](https://5thsrd.org/rules/feats/) (CC-BY-4.0, Wizards of the Coast)

Optional rule (many tables use it by default, but it's toggleable). A feat represents a talent or specialization beyond normal class features.

- **Gained** by trading an Ability Score Improvement (see [leveling-xp.md](leveling-xp.md)) for a feat instead of a stat bump.
- **Prerequisites**: some feats require a minimum ability score or other condition; losing the prerequisite later suspends the feat until it's regained.
- A given feat can normally only be taken once, unless its text says otherwise.

Example — **Grappler** (prerequisite STR 13+): advantage on attack rolls against a creature you're grappling; can spend an action to pin a grappled creature (both become restrained on success).
